
Parfait. On a donc déjà PHP 8.4.26 CLI installé sur Debian. C'est un bon début pour NexusSchool ! Nous allons conserver cette version et vérifier sa compatibilité avec le projet avant d'installer les composants restants.

L'ordre sera : extensions PHP → Composer → MariaDB → configuration Apache → déploiement Laravel. Nous ne toucherons pas à ton site HTML actuel.

## 1. Vérifier PHP et Apache

Sur ton serveur Debian, exécute :

```
php -v
which php
php --ini
php -m
apache2 -v
sudo apache2ctl -S
```

Le point important : PHP CLI fonctionne dans le terminal, mais cela ne garantit pas encore qu'Apache puisse exécuter PHP. Nous vérifierons et configurerons cela séparément.

## 2. Installer les extensions PHP nécessaires

D'abord, vérifie la version de Debian :

```
cat /etc/os-release
```

Si tu utilises Debian 13 (Trixie) et que PHP 8.4 vient des dépôts Debian, tu peux installer les extensions suivantes :

```
sudo apt update

sudo apt install -y \
  php8.4-cli \
  php8.4-common \
  php8.4-mysql \
  php8.4-xml \
  php8.4-curl \
  php8.4-mbstring \
  php8.4-zip \
  php8.4-bcmath \
  php8.4-intl \
  php8.4-gd \
  php8.4-opcache \
  unzip \
  git \
  curl
```

Si `apt` indique qu'un paquet est introuvable, ne cherche pas à ajouter un dépôt tiers immédiatement. Envoie-moi l'erreur : PHP 8.4.26 peut provenir d'une source différente, et nous devons garder une installation cohérente.

Vérifie ensuite :

```
php -m
php -r 'echo PHP_VERSION, PHP_EOL;'
```

Nous confirmerons notamment la présence de `pdo_mysql`, `mbstring`, `openssl`, `xml`, `curl`, `zip` et `bcmath`.

## 3. Installer Composer

Une fois les extensions installées, nous installerons Composer, le gestionnaire de dépendances PHP utilisé par Laravel.

Vérifie d'abord :

```
command -v composer
```

S'il n'est pas installé, tu peux utiliser le paquet Debian :

```
sudo apt install -y composer
composer --version
```

Nous vérifierons ensuite la compatibilité des dépendances du projet avec Composer et le fichier `composer.lock`. Il ne faudra pas lancer une mise à jour globale des dépendances.

## 4. Installer MariaDB

Nous créerons une base de données dédiée à la préproduction, sans remplacer celle de ton environnement Windows/XAMPP.

```
sudo apt install -y mariadb-server mariadb-client
sudo systemctl enable --now mariadb
sudo systemctl status mariadb --no-pager
```

Vérifie que le serveur répond :

```
sudo mariadb -e "SELECT VERSION();"
```

Ne crée pas encore la base NexusSchool et ne restaure aucun dump. Nous devons d'abord confirmer les paramètres de connexion et le schéma attendu par la version actuelle du projet.

## 5. Vérifier les dépendances réelles de NexusSchool

Sur ton PC Windows, dans PowerShell :

```
cd C:\xampp\htdocs\NexusSchool

php artisan --version
composer --version
git status --short
```

Si Composer est installé sur ton PC, vérifie également les contraintes PHP du projet :

```
composer check-platform-reqs
```

Attention : cette dernière commande vérifie l'environnement dans lequel elle est exécutée. Elle ne valide donc pas encore les extensions installées sur Debian.
