Parfait. On va donc configurer un nom de domaine privé pour NexusSchool, accessible uniquement à travers Tailscale, sans acheter de domaine public et sans toucher aux installations déjà fonctionnelles.

Je te recommande cette architecture :

- Nom principal : `nexusschool.test`
- Exemple d’espace école : `ebenezer.nexusschool.test`
- Serveur : ta machine Debian, accessible sur le réseau Tailscale.
- Apache : dirigera les requêtes vers NexusSchool une fois le projet déployé.
- DNS privé : permettra à tes appareils de résoudre ces noms vers ton serveur.

Point important : Tailscale fonctionne déjà, mais cela ne crée pas automatiquement les enregistrements DNS pour `nexusschool.test` et ses sous-domaines. Nous devons prévoir une résolution DNS adaptée, plutôt que supposer que MagicDNS suffira.

## Étape 1 — Configurer le DNS privé sur Debian

Le domaine `.test` est réservé aux environnements de test. Nous pouvons l’utiliser sans acheter de domaine public.&#x20;

Sur le terminal de Debian, exécute ce bloc. Il installe `dnsmasq` si nécessaire et configure la résolution du domaine privé vers l’adresse Tailscale de ton serveur.

```
sudo apt install -y dnsmasq

TAILSCALE_IP="$(tailscale ip -4 | head -n 1)"

if [ -z "$TAILSCALE_IP" ]; then
    echo "ERREUR : aucune adresse IPv4 Tailscale disponible."
else
    echo "Adresse Tailscale du serveur : $TAILSCALE_IP"

    sudo tee /etc/dnsmasq.d/nexusschool.conf >/dev/null <<EOF
# DNS prive NexusSchool, accessible via Tailscale uniquement
listen-address=$TAILSCALE_IP
bind-dynamic
no-resolv
local=/nexusschool.test/
address=/nexusschool.test/$TAILSCALE_IP
EOF

    sudo dnsmasq --test
fi
```

Important : ce bloc prépare la configuration et vérifie sa syntaxe, mais ne redémarre pas encore le service. Si une erreur apparaît, arrête-toi et envoie-moi le message.

Si le résultat indique `syntax check OK`, exécute ensuite :

```
sudo systemctl restart dnsmasq
sudo systemctl status dnsmasq --no-pager
```

Le résultat attendu est un service `active (running)`.

## Étape 2 — Relier ce DNS à Tailscale

Depuis la console d’administration Tailscale :

1. Ouvre la page DNS : [Administration DNS Tailscale](https://login.tailscale.com/admin/dns?utm_source=chatgpt.com).
2. Dans les serveurs de noms, ajoute un serveur personnalisé avec l’adresse IPv4 Tailscale de ta machine Debian.
3. Configure ce serveur comme serveur de noms restreint (split DNS) pour `nexusschool.test`.
4. Enregistre les modifications.

Le split DNS indique aux appareils Tailscale d’envoyer les requêtes correspondant à ce domaine vers ton serveur DNS privé, sans remplacer nécessairement leur DNS habituel pour le reste d’Internet.&#x20;

## Étape 3 — Tester la résolution

Sur un appareil connecté à ton réseau Tailscale, teste :

```
nexusschool.test
ebenezer.nexusschool.test
zinda.nexusschool.test
```

Les trois noms doivent résoudre vers l’adresse Tailscale de Debian. Apache devra ensuite être configuré pour répondre correctement à ces noms.

Pour le moment, ne modifie pas les VirtualHosts Apache et ne transfère pas encore NexusSchool. Termine d’abord le DNS et envoie-moi le résultat de `sudo systemctl status dnsmasq --no-pager` ; nous passerons ensuite à la configuration des noms dans Apache, puis au déploiement de NexusSchool et à sa base de préproduction.
