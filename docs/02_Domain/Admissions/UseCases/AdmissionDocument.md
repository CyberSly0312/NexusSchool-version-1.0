# Admission Document Use Cases

## Purpose

Defines document management processes.

---

# Supported Use Cases

- Upload Document
- Verify Document
- Approve Document
- Reject Document
- Replace Document
- Archive Document

---

## Business Rules

- Supported formats only.
- Approved Documents cannot be modified.
- Rejected Documents may be replaced.
