# Admission Requirement Workflow

## Purpose

Manage Admission Requirements throughout an Admission Cycle.

---

# Trigger

Admission Manager creates a Requirement.

---

# Workflow Steps

1. Create Requirement.
2. Define Type.
3. Define Mandatory Status.
4. Associate Programs.
5. Activate Requirement.
6. Verify Applicant Compliance.
7. Mark Requirement Completed.
8. Archive Requirement.

---

# Status Flow

Draft

↓

Active

↓

Completed

↓

Archived

---

# Exceptions

- Duplicate Requirement
- Invalid Configuration
- Requirement Already Active

---

# Notifications

- Requirement Activated
- Requirement Completed

---

# Result

Requirement successfully managed.
