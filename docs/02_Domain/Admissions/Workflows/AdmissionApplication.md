# Admission Application Workflow

## Purpose

This workflow describes the complete lifecycle of an Admission Application from creation to final processing.

---

# Trigger

Applicant starts a new Admission Application.

---

# Preconditions

- Admission Cycle is Open.
- Applicant account is active.
- Eligibility requirements are satisfied.

---

# Workflow Steps

1. Applicant creates an Application.
2. Applicant completes personal information.
3. Applicant selects Program.
4. Applicant uploads required Documents.
5. System validates mandatory fields.
6. Applicant submits Application.
7. Application status changes to Submitted.
8. Admission Officer reviews Application.
9. Missing information generates correction request.
10. Valid Applications proceed to Evaluation.

---

# Exceptions

- Admission Cycle Closed
- Duplicate Application
- Missing Documents
- Invalid Data

---

# Notifications

- Application Submitted
- Application Returned
- Application Accepted for Review

---

# Result

Application is ready for verification and evaluation.
