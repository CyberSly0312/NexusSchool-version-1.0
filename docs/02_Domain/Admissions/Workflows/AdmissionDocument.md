# Admission Document Workflow

## Purpose

Manage Admission Documents from upload to verification.

---

# Trigger

Applicant uploads a Document.

---

# Workflow Steps

1. Upload Document.
2. Validate File Format.
3. Store Document.
4. Assign Requirement.
5. Officer Reviews Document.
6. Verify Authenticity.
7. Approve or Reject.
8. Archive Document.

---

# Status Flow

Uploaded

↓

Pending Verification

↓

Approved

OR

Rejected

↓

Archived

---

# Exceptions

- Unsupported Format
- Corrupted File
- Duplicate Upload
- Verification Failed

---

# Notifications

- Document Uploaded
- Verification Requested
- Document Approved
- Document Rejected

---

# Result

Document becomes part of the Admission record.
