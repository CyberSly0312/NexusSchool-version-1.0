# Admission Cycle Workflow

## Purpose

Manage the lifecycle of an Admission Cycle.

---

# Trigger

Admission Manager creates a new Admission Cycle.

---

# Workflow Steps

1. Create Cycle.
2. Configure Dates.
3. Configure Programs.
4. Configure Requirements.
5. Publish Cycle.
6. Open Cycle.
7. Receive Applications.
8. Close Cycle.
9. Archive Cycle.

---

# Status Flow

Draft

↓

Published

↓

Open

↓

Closed

↓

Archived

---

# Exceptions

- Invalid Dates
- Overlapping Cycles
- Active Applications

---

# Notifications

- Cycle Published
- Cycle Opened
- Cycle Closed

---

# Result

Admission Cycle completed successfully.
