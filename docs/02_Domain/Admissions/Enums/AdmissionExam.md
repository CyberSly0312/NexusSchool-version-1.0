# Admission Exam Status Enum

## Purpose

Represents the lifecycle of an Admission Examination.

---

## Values

| Value | Description |
|--------|-------------|
| Scheduled | Examination scheduled. |
| Registered | Applicant registered. |
| InProgress | Examination in progress. |
| Completed | Examination completed. |
| Graded | Examination graded. |
| Published | Results published. |
| Cancelled | Examination cancelled. |
