# Admission Offer Status Enum

## Purpose

Represents the lifecycle of an Admission Offer.

---

## Values

| Value | Description |
|--------|-------------|
| Draft | Offer generated. |
| Published | Offer sent. |
| Accepted | Offer accepted. |
| Declined | Offer declined. |
| Expired | Offer expired. |
| Revoked | Offer cancelled. |
| Archived | Historical record. |
