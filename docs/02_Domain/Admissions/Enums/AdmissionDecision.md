# Admission Decision Status Enum

## Purpose

Represents the outcome of an Admission Decision.

---

## Values

| Value | Description |
|--------|-------------|
| Pending | Awaiting review. |
| UnderReview | Decision in progress. |
| Approved | Applicant admitted. |
| Rejected | Applicant not admitted. |
| Waitlisted | Applicant placed on waiting list. |
| Published | Decision published. |
| Archived | Historical record. |
