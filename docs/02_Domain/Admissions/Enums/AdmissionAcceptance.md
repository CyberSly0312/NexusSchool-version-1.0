# Admission Acceptance Status Enum

## Purpose

Represents the lifecycle of an Admission Acceptance.

---

## Values

| Value | Description |
|--------|-------------|
| Pending | Awaiting applicant response. |
| Accepted | Admission accepted. |
| Declined | Admission declined. |
| EnrollmentInitiated | Enrollment started. |
| Completed | Enrollment completed. |
| Cancelled | Admission cancelled. |
