# Admission Application Status Enum

## Purpose

Represents the lifecycle of an Admission Application.

---

## Values

| Value | Description |
|--------|-------------|
| Draft | Application is being prepared. |
| Submitted | Application submitted for review. |
| UnderReview | Application under evaluation. |
| PendingCorrection | Applicant must correct submitted information. |
| Approved | Application approved. |
| Rejected | Application rejected. |
| Withdrawn | Application withdrawn by applicant. |
| Archived | Application archived. |
