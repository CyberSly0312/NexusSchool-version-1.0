# Admission Requirement Type Enum

## Purpose

Represents the category of an Admission Requirement.

---

## Values

| Value | Description |
|--------|-------------|
| Document | Official document required. |
| Examination | Admission examination required. |
| Interview | Interview required. |
| Medical | Medical clearance required. |
| Financial | Financial clearance required. |
| Academic | Academic prerequisite. |
| Administrative | Administrative requirement. |
| Other | Other requirement. |
