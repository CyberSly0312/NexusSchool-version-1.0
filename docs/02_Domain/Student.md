# Student

## Purpose

Represents an enrolled learner within Nexus School.

---

## Description

A Student is the central academic entity participating in learning activities, assessments, attendance, finance, library, transportation, hostel, and communication services.

---

## Core Attributes

- Student Number
- Full Name
- Gender
- Date of Birth
- Nationality
- Admission Date
- Current Status
- Education Level

---

## Relationships

- Program
- Department
- Section
- Class
- Parents
- Academic Records
- Attendance
- Finance
- Library
- Hostel
- Transport

## Business Rules

- Unique Student Number.
- One active enrollment.
- Complete academic history retained.
