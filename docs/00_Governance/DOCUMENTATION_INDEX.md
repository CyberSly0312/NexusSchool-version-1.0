# 1. Purpose

The Documentation Index is the primary navigation entry point for the Nexus School documentation repository.

Its objective is to help contributors quickly locate the appropriate documentation without needing to understand the entire repository structure.

This document complements, but does not replace:

- README.md
- Documentation Map
- Documentation Governance

---

# 2. Before You Start

If you are new to the project, read the following documents in order:

1. README
2. Documentation Governance
3. Documentation Map
4. Architecture Overview

This sequence provides the minimum knowledge required before contributing to the project.

# 8. Maintenance

The Documentation Index shall be reviewed whenever:

- new documentation families are introduced;
- documentation structure changes significantly;
- governance processes evolve.

It should remain concise and stable.

It is not intended to become a complete inventory of every document in the repository.

---

# Final Statement

The Documentation Index is the official entry point for navigating the Nexus School knowledge base.

Its purpose is to guide contributors toward the correct source of information, reduce unnecessary searching, and improve the discoverability of the project's documentation without altering the existing repository structure.
