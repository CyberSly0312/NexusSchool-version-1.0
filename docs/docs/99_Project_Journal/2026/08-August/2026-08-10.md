# 1. Session Overview

Today's session was a **repository hardening effort** (ESP-002), not a feature
sprint. The goal was to remove a class of PHPStan findings where the Attendance
and Class Council authorization traits accepted a generic
`Illuminate\Database\Eloquent\Model` while reading `$model->school_id` as a
magic property — a read PHPStan cannot statically verify, which had to be pinned
in the error baseline.

The session replaced the implicit ownership assumption with an **explicit
contract** (`SchoolOwned` / `getSchoolId()`), migrated the two affected traits
and the six tenant-scoped aggregates, remediated UTF-8 corruption in 11 factory
files, and closed out with full green quality gates. The effort was verified
forensically and the governance documentation was updated.

---

# 2. Objectives

The objectives of today's session were to

* Replace implicit `school_id` magic-property reads in the authorization traits
  with a statically-verifiable ownership contract.
* Keep authorization semantics **byte-identical** (type-safety change only).
* Resolve the findings without touching `phpstan-baseline.neon`.
* Remediate the UTF-8 mojibake found in factory files.
* Land the effort green under PHPStan, Pest and Pint.
* Record the outcome in the governance documents and close ESP-002.

# 3. Work Completed

## Contract and trait

* `app/Contracts/SchoolOwned.php` (new) — `getSchoolId(): string`, the explicit
  representation of tenant ownership for authorization subjects.
* `app/Traits/HasSchoolId.php` — `@property string $school_id` PHPDoc, `creating`
  callback typed `self $model`, and a `getSchoolId()` implementation of the
  contract. The pre-existing `&& tenant()` observer guard is preserved.

## Aggregates implementing `SchoolOwned`

* Attendance: `AttendanceAlert`, `AttendanceCorrection`, `AttendanceRecord`,
  `AttendanceSession`, `AttendanceSummary`.
* Class Council: `CouncilSession`.

All six carry a non-nullable `school_id` column, so the contract is truthful for
every row.

## Authorization traits

* `HandlesAttendanceAuthorization` and `HandlesClassCouncilAuthorization` now
  type their subject as `SchoolOwned` and read the school through
  `getSchoolId()`. `super_admin` bypass, cross-school denial, never-delete rules
  and central-school context are preserved verbatim.

## UTF-8 remediation

* 11 factory files with corrupted French characters were repaired to proper
  UTF-8; no unrelated changes were introduced.

---

# 4. Architectural Decisions

## Explicit contract over baseline suppression

The root cause was implicit ownership. The fix was compared against four
alternatives (error suppression, baseline expansion, `school_id` on the base
`Model`, blind `getAttribute` cast) and the **explicit `SchoolOwned` contract**
was chosen: the traits demand a static guarantee, only truly tenant-scoped
models implement it, and PHPStan verifies it at every call site.

The contract is additive and does not change the existing multi-tenancy
architecture, so no ADR was required.

# Third Session — SPR-009.5 Academic Policies Engine

# 1. Session Overview

Implemented the **Academic Policies Engine** — the exclusive origin of academic
rules mandated by ARCHITECTURE_DECISIONS §6. Started from the reconciled state
(SPR-009.5 correctly documented as Planned / Not Started with only two empty
stub adapters). Delivered a complete new bounded context
(`App\Domains\AcademicPolicy`) and rewired the Report Card and Academic
Communication stub adapters to read policies from the database. No commit
created; working tree remains uncommitted (pre-existing refonte untouched).

# 2. Decisions / Changes

* **New bounded context** `App\Domains\AcademicPolicy` (Domain / Application /
  Infrastructure / Filament) — not an extension of the Academic Framework
  domain. Follows the SPR-010 → SPR-013 engine conventions.
* **Architectural decision gate resolved from code evidence:** policy types
  implied by existing consumers (`grading_scale`, `honor_threshold`,
  `assessment_rules`) plus config-driven hard-coded rules in Gradebook
  (letter grades / appreciation / standing) and Class Council (promotion).
  Mandatory now = engine + the two existing adapters; rewiring Gradebook /
  Class Council / Assessment computation = deferred (documented, no code).
* **Normalized data model:** single `academic_policies` table, typed value
  (`string|integer|float|boolean|json`) stored as JSON and normalized on read,
  scope `school|academic_year|subject`, unique `(school_id, key, scope)`,
  soft deletes, audit via events → `AuditLog`.
* **No invented values:** undefined policy ⇒ `[]`/`null` (identical to the
  previous stub behavior ⇒ zero regression). No BF/CI/ML/NE/TG/BJ defaults.
* **Strict typing fixed a real bug:** JSON stores whole floats as ints; a
  `float` policy now always reads back as float (`PolicyValue::fromStored`
  normalization + model `value` accessor).
* **PHPStan-clean without baseline edits:** `@property` model PHPDocs,
  `SchoolOwned` contract typing for the auth trait, explicit
  `Filament\Schemas\Components\Utilities\Get` import (the `Filament\Forms\Get`
  alias does not exist in Filament 5.6.8), `mapWithKeys` enum options,
  `default` match arm instead of an always-true boolean arm.
* **Permissions auto-generated:** `PermissionGroup::AcademicPolicy` ⇒
  `academic_policy.view/create/update/delete` flow through the existing
  `PermissionSeeder` (no seeder change).
* **Filament surface:** `AcademicPolicyResource` (group "Académique", sort 120)
  registered in `SchoolAdminPanelProvider`; Create/Edit pages coerce the value
  and clear scope references for school-scoped policies.
* **Discovery during quality gates:** full-repository Pint reports **419
  pre-existing** failing files in the uncommitted refonte (legacy models,
  resources, Plugin/Assessment legacy pages, seeders, migrations, lang, legacy
  tests) — untouched, tracked in TECHNICAL_DEBT, reported separately.
