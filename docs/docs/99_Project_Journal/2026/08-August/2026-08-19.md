# 2026-08-19 — Source-Domain Integration

## Session Focus

SPR-014 source-domain integration: wiring Report Card and Academic Communication to the RecordsLifecycle metadata envelope through the contract/adapter pattern.

## What Was Done

### Report Card Integration (confirmed pre-existing)

ReportCard already had full RecordsLifecycle integration from the first slice stabilization:
- `RecordsLifecycleContract` in `ReportCard/Domain/Contracts/`
- `RecordsLifecycleAdapter` in `ReportCard/Infrastructure/Contracts/`
- Binding in `ReportCardServiceProvider`
- All three actions (`GenerateReportCardAction`, `PublishReportCardAction`, `ArchiveReportCardAction`) use the contract
- 5 integration tests

### Academic Communication Integration (implemented this session)

Created the same pattern for AcademicCommunication:

**New files:**
- `app/Domains/AcademicCommunication/Domain/Contracts/RecordsLifecycleContract.php`
- `app/Domains/AcademicCommunication/Infrastructure/Contracts/RecordsLifecycleAdapter.php`
- `tests/Feature/Domains/AcademicCommunication/AcademicCommunicationRecordsLifecycleIntegrationTest.php`

**Modified files:**
- `app/Domains/AcademicCommunication/AcademicCommunicationServiceProvider.php` — added binding
- `app/Domains/AcademicCommunication/Application/Actions/GenerateDocumentAction.php` — added lifecycle registration
- `app/Domains/AcademicCommunication/Application/Actions/PublishDocumentAction.php` — added lifecycle publication
- `app/Domains/AcademicCommunication/Application/Actions/ArchiveDocumentAction.php` — added lifecycle archival

**Key design decisions:**
- `source_domain` = `academic_communication`
- `source_type` = the `DocumentType` enum value (e.g., `report_card`, `council_minutes`, etc.)
- `source_id` = the `AcademicDocument` key
- `source_version` = the document number
- `academic_context` = year/term/class/section/student/staff IDs (filtered for nulls)
- Registration happens in `GenerateDocumentAction`, so all document types get lifecycle tracking

### Test Fix

Updated `ReportCardRecordsLifecycleIntegrationTest::lifecycle records from different schools remain isolated` to query by `source_domain = 'report_card'` since generating a report card now creates lifecycle records in both domains (ReportCard + AcademicCommunication).

### PHPStan Fix

Used `$document->getAttributes()['document_type']` instead of `$document->document_type->value` in `PublishDocumentAction` and `ArchiveDocumentAction` to avoid the `Cannot access property $value on string` baseline count mismatch. This accesses the raw (uncast) attribute value which PHPStan treats as `mixed`, avoiding the error while returning the correct string at runtime.
