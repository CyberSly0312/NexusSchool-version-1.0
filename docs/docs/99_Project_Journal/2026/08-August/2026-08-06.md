# 1. Session Overview

Today's objective was to complete the Class Council Engine — the final engine
of Phase 2 (Academic Intelligence). The engine is the exclusive
academic-validation layer of the platform: it validates **published** academic
results, records council decisions and exposes **only published decisions** to
the downstream engines (Academic Communication, Report Card) through **domain
contracts + adapters**.

The session delivered the full engine (domain, application, infrastructure,
presentation, schema, permissions), its test suite, static analysis and the
governance documentation. All three quality gates are green.

---

# 2. Objectives

The objectives of today's session were to

* Build the Class Council engine as the exclusive academic-validation layer.
* Enforce a forward-only session lifecycle with immutable published sessions.
* Record decisions with permanent codes and audited, approved overrides.
* Keep deliberations confidential (never exposed through a contract).
* Wire Report Card and Academic Communication to consume published decisions
  through contracts.
* Land the engine green under Pest, PHPStan and Pint.

# 4. Architectural Decisions

## Class Council owns academic validation

Academic validation belongs exclusively to the Class Council engine. The
automatic decision rule is never duplicated elsewhere.

## Published sessions are immutable

Publishing freezes a session; decisions and deliberations are only accepted
while Convened.

## Overrides require justification + approval + audit

Every override snapshots the overridden automatic decision, so the history
always shows what the automatic rule would have said.

## Deliberations never cross a contract

Confidential deliberation records can never reach a downstream engine or a
rendered document — only published decisions do.
