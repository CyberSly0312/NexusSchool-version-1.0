# AI Knowledge Base

## Purpose

Define the information sources available to the AI Assistant.

---

# Knowledge Sources

- Application Documentation
- Business Rules
- User Manuals
- Academic Policies
- School Settings
- Tenant Configuration

---

# Dynamic Knowledge

The AI may use:

- Student Information
- Attendance Data
- Financial Data
- Reports
- Timetables

Only when authorized.

---

# Knowledge Scope

The assistant only accesses information within the current tenant.

Cross-tenant access is prohibited.

---

# Knowledge Refresh

Knowledge is refreshed whenever:

- Settings change
- Business rules change
- Documentation changes

---

# Privacy

Private information must never be exposed outside authorized contexts.

---

# Future Sources

- Ministry regulations
- Curriculum documents
- School handbooks
- Internal policies
