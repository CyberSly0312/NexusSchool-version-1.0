# Prompt Engineering

## Purpose

Define standards for prompts used by the Nexus School AI Assistant.

---

# Objectives

- Accurate responses
- Consistent behavior
- Secure interactions
- Context-aware assistance

---

# Prompt Structure

Each prompt should include:

- User Role
- Tenant Context
- Current Module
- User Request
- Relevant Business Rules

---

# Example Context

Role

Teacher

Module

Attendance

Task

Generate attendance summary for Grade 6.

---

# Prompt Principles

- Be clear
- Be specific
- Include context
- Avoid ambiguity
- Respect permissions

---

# Response Guidelines

Responses should:

- Be concise
- Be factual
- Cite available data when possible
- Avoid speculation

---

# Safety

Prompts must not expose:

- Secrets
- Credentials
- Cross-tenant information
- Internal system configuration

---

# Continuous Improvement

Prompt templates should be reviewed and refined based on user feedback and platform evolution.
