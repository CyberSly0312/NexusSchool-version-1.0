# Tables Guidelines

## Purpose

Define standards for data tables used throughout Nexus School.

---

# Objectives

- Easy navigation
- Fast searching
- Efficient data management

---

# Standard Features

Every table should support:

- Pagination
- Sorting
- Searching
- Filtering
- Export
- Bulk Actions

---

# Columns

Columns should be:

- Readable
- Sortable when appropriate
- Hideable
- Responsive

---

# Filters

Examples

- Academic Year
- Status
- Class
- Department
- Date
- Payment Status

---

# Search

Global search should be available whenever practical.

---

# Actions

Each row may contain:

- View
- Edit
- Delete
- Print
- Export

Actions depend on user permissions.

---

# Bulk Actions

Support:

- Export
- Delete
- Archive
- Assign
- Approve

---

# Empty State

Display a friendly message when no records exist.

Offer a quick action to create the first record.

---

# Loading

Display loading indicators while retrieving data.

---

# Performance

Large datasets should use:

- Server-side pagination
- Lazy loading
- Efficient database queries

---

# Mobile

Tables should remain usable on tablets.

Cards may replace tables on smaller screens.
