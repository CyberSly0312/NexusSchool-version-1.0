# Navigation Guidelines

## Purpose

Provide a predictable and consistent navigation experience.

---

# Objectives

- Easy to learn
- Fast access
- Minimal clicks
- Role-specific navigation

---

# Sidebar

Sidebar contains:

- Dashboard
- Academic
- Students
- Teachers
- Finance
- Reports
- Settings

Visible items depend on user permissions.

---

# Navigation Groups

Examples

Academic

Finance

People

Administration

Communication

Reports

Settings

---

# Icons

Each navigation item includes an icon.

Icons complement labels and never replace them.

---

# Search

Global navigation search allows quick access to:

- Students
- Teachers
- Classes
- Invoices
- Reports

---

# Breadcrumbs

Every page includes breadcrumbs for orientation.

---

# Favorites

Users may pin frequently accessed pages.

---

# Mobile Navigation

Navigation collapses into a drawer.

Landscape mode is recommended for tablets.
