# UI Components

## Purpose

Standardize reusable interface components across Nexus School.

---

# Buttons

Types

- Primary
- Secondary
- Success
- Warning
- Danger

---

# Cards

Used for:

- Statistics
- KPIs
- Information
- Summaries

---

# Badges

Represent:

- Status
- Roles
- Categories
- Priorities

---

# Modals

Used for:

- Confirmations
- Quick Forms
- Details
- Previews

---

# Drawers

Used for secondary workflows without leaving the current page.

---

# Tabs

Organize related information.

---

# Accordions

Display expandable content.

---

# Alerts

Types

- Success
- Warning
- Error
- Information

---

# Empty States

Every empty page should explain:

- Why no data exists
- What action the user should take

---

# Loading States

Display skeleton loaders or progress indicators.

---

# Charts

Use charts only when they improve understanding.

Avoid unnecessary visual complexity.

---

# Consistency

Reusable components must maintain identical behavior throughout the platform.
