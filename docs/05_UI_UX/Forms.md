# Forms Guidelines

## Purpose

Define standards for building forms across the Nexus School platform.

---

# Objectives

- Simple
- Consistent
- Fast
- Accessible
- Error-resistant

---

# Form Structure

Every form should include:

- Clear title
- Logical sections
- Required field indicators
- Validation messages
- Submit button
- Cancel button

---

# Sections

Large forms should be divided into sections.

Examples

- Personal Information
- Academic Information
- Contact Information
- Financial Information
- Documents

---

# Tabs

Use tabs when forms contain many related sections.

---

# Validation

Validation occurs:

- On input (where appropriate)
- Before submission
- On the server

---

# Required Fields

Clearly identify required fields.

Avoid unnecessary mandatory inputs.

---

# Field Types

Use appropriate components:

- Text Input
- Select
- Multi Select
- Date Picker
- Time Picker
- Toggle
- Checkbox
- Radio Buttons
- File Upload
- Rich Editor
- Repeater

---

# Reactive Forms

Use reactive fields when values depend on previous selections.

Example

Country

↓

Region

↓

City

---

# File Uploads

Support:

- Images
- PDF
- Office Documents

Display upload progress and validation errors.

---

# Auto Save

Enable auto-save only where appropriate.

---

# Accessibility

Support:

- Keyboard navigation
- Labels
- Screen readers
- Proper focus order

---

# Error Messages

Messages should:

- Be human-readable
- Explain the problem
- Suggest corrective action

---

# Performance

Large forms should use lazy loading where appropriate.
