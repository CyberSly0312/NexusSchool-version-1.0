# Dashboard Guidelines

## Purpose

Provide meaningful dashboards tailored to each user role.

---

# Objectives

- Immediate visibility
- Action-oriented interface
- Personalized experience

---

# Dashboard Components

- KPIs
- Charts
- Notifications
- Recent Activity
- Quick Actions

---

# School Administrator Dashboard

Displays:

- Total Students
- Total Teachers
- Attendance Rate
- Outstanding Fees
- Revenue
- Academic Calendar
- Announcements

---

# Teacher Dashboard

Displays:

- Today's Classes
- Timetable
- Pending Attendance
- Pending Grades
- Notifications

---

# Parent Dashboard

Displays:

- Children
- Attendance
- Academic Results
- Outstanding Fees
- Messages

---

# Student Dashboard

Displays:

- Timetable
- Assignments
- Attendance
- Results
- Library Loans

---

# Accountant Dashboard

Displays:

- Revenue Today
- Pending Payments
- Outstanding Balances
- Recent Transactions
- Financial Reports

---

# Super Admin Dashboard

Displays:

- Active Schools
- Active Subscriptions
- Revenue
- Server Health
- Queue Status
- Monitoring Alerts
