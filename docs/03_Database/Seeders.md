# Seeder Strategy

## Purpose

Populate the system with required default data.

---

## Mandatory Seeders

- Roles
- Permissions
- Countries
- Currencies
- Languages
- Academic Levels
- Academic Terms

---

## Development Seeders

- Demo Students
- Demo Teachers
- Demo Parents
- Demo Classes

---

## Testing Seeders

Generate realistic datasets for automated tests.

---

## Production Rules

Only reference data is seeded automatically.

Business data is never seeded in production.

---

## Best Practices

- Seeders must be idempotent.
- Use factories whenever possible.
- Maintain deterministic reference data.
